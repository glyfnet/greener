# D-02: Geographic scope

- Status: Accepted
- Date: 2026-11-24
- Source: [specification Section 2, Decision log](../specification.md#2-decision-log)

## Context and problem

Geographic scope: what does Greener do? This decision is recorded in the specification's decision log. The specification is the source of truth; this file records the decision in MADR form so that a later change can supersede it.

## Decision

Australia only. NSW first for MVP.

## Consequences

Use the Atlas of Living Australia (ALA), state data and council lists. No global fallback in release 1. MVP uses NSW state data and NSW council lists only; other states come in Phase 2.
