# D-15: Global KB content

- Status: Accepted
- Date: 2026-11-24
- Source: [specification Section 2, Decision log](../specification.md#2-decision-log)

## Context and problem

Global KB content: what does Greener do? This decision is recorded in the specification's decision log. The specification is the source of truth; this file records the decision in MADR form so that a later change can supersede it.

## Decision

Two tiers: **open content** (full text, only with an open licence or permission) and a **link catalogue** (URL, metadata and a thorough summary in our own words). No private KB.

## Consequences

The repository stays fully public. Claude reads link-catalogue sources live when web access is on (Section 7.4).
