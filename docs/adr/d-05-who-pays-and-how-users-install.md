# D-05: Who pays, and how users install

- Status: Accepted
- Date: 2026-11-24
- Source: [specification Section 2, Decision log](../specification.md#2-decision-log)

## Context and problem

Who pays, and how users install: what does Greener do? This decision is recorded in the specification's decision log. The specification is the source of truth; this file records the decision in MADR form so that a later change can supersede it.

## Decision

Plugin with skills plus a **stateless remote MCP server**. Users install from Claude with no local setup.

## Consequences

Works on claude.ai web, desktop and mobile. Developer pays hosting only.

D-05 and D-06 changed on 24 Nov 2026 so that non-technical users need no install and no local setup (specification Section 2).
